# Director notes

Notas de direção devem dizer **o que mudar** e, quando possível, **quanto**.

## Vocabulário útil

### Tempo
- segure por +N frames;
- corte N frames antes/depois;
- acelere/desacelere para X%;
- antecipe/atrase a entrada;
- encurte a transição.

### Corte
- hard cut;
- match cut;
- cut on action;
- remove fade;
- use dip/flash apenas se o brief pedir.

### Câmera
- push in / pull out;
- pan / tilt;
- truck / pedestal;
- orbit;
- rack focus simulado;
- crop/zoom;
- reduza/aumente amplitude.

### Layout
- mova X% no eixo;
- aumente/reduza escala;
- troque alinhamento;
- aumente respiro;
- mantenha produto dentro da safe area;
- eleve/rebaixe hierarquia.

### Motion
- ease in/out;
- linear;
- overshoot;
- spring mais/menos amortecida;
- stagger;
- wipe;
- reveal;
- mask;
- parallax.

## Formato recomendado

~~~text
Cena 03
Problema: preço entra cedo e compete com o produto.
Mudança: segure o preço por +8 frames; produto fica sozinho no primeiro beat.
Motion: reduza o push-in para 70% da amplitude atual.
Transição: hard cut para cena 04.
Não alterar: preço, fonte da oferta, cor do produto.
~~~

Evite:
- "mais premium";
- "mais cinematográfico";
- "deixa melhor";
- "faz mais Apple".

Converta adjetivos em decisões observáveis.
