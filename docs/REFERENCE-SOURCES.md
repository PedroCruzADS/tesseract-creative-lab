# Reference sources

Referências são matéria-prima de direção, não templates para copiar.

## Decomposição

Para cada referência, extraia:
- pacing;
- beat structure;
- hierarquia;
- composição;
- tipografia;
- câmera;
- mecanismo de transição;
- shared elements;
- densidade;
- uso de produto/UI;
- payoff;
- tratamento de áudio.

Nunca transcreva uma sequência inteira frame a frame.

## Estratégia de múltiplas referências

Quando possível use referências complementares:

- referência A: ritmo/motion;
- referência B: composição/hierarquia;
- referência C: microinteração/transição.

O storyboard deve explicar o que veio de cada referência.

## Reference DNA

O agente deve converter uma referência em uma ficha como:

{
  "hook_seconds": 1.4,
  "density": "medium",
  "camera_rule": "one intentional move per scene",
  "transition_grammar": ["shared-element morph", "mask reveal", "shape flood"],
  "type_behavior": "masked rise, short holds",
  "commercial_payoff": "last third",
  "avoid": ["crossfade default", "particles"]
}

Depois adapte o DNA ao produto, marca, oferta e placement atuais.
